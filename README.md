# ANDY98563 — Financial Technology Solutions

**Smarter Payments. Better Possibilities.**

A responsive, multi-page static FinTech concept website with the Black Platinum palette.

## Pages
- `index.html` — Home
- `solutions.html` — Solution concepts
- `wallet.html` — Interactive virtual card and transfer simulation
- `dashboard.html` — Interactive fictional dashboard
- `about.html` — About the brand
- `faq.html` — FAQ
- `contact.html` — Demo-only contact form
- `privacy.html` — Privacy notice
- `terms.html` — Terms of use

## Run locally
Open `index.html` in a browser. No build step required.

## Deploy to GitHub Pages
Upload all files and the `assets` folder to the root of a public repository. Under Settings → Pages, select Deploy from a branch, `main`, `/ (root)`.

## Important
This is a **concept website only**. There are no real accounts, payment services, financial products, transfers, card issuance, or functional contact delivery. Sample financial data is fictional. Review all legal, compliance and privacy disclosures before any commercial launch.
